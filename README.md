# TymFlo Navigator - Dayna Foster Dashboard

A live operating dashboard for Dayna Foster's **Home Help Agency Ownership Education** business.

Built with React + Vite + Tailwind CSS. Deployed to GitHub Pages via GitHub Actions.

## Features

- **Home** — Next best action + phase progress + gate status
- **Plan** — Interactive task checklist with subtasks, status, notes, and asset links
- **Products** — Live funnel with customer counts and conversion rates
- **Customers** — Client journey map with Andrea persona
- **Results** — Editable metrics, Revenue Planner calculator, time tracking
- **Resources** — Learning log, monthly notes, content ideas, tool links

All data persists locally via `localStorage` under key `tymflo-dayna`.

## Deploy

Push to `main` — GitHub Actions builds and deploys automatically to GitHub Pages.
